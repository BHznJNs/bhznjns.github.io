2026 上半年小结

想来又是好久没有写阶段总结了，乘着 2026 年上半年刚过去，赶紧把这半年发生的事记录一下吧。

开发

Dais

上半年我的精力基本放在 Dais 这个桌面 Agent 项目上。

这个项目其实我在去年的五六月份就想到要做这么一个软件，当时 Claude Code 刚刚开始流行，其它做 Coding Agent 产品的公司也跟风做类似的 Coding CLI 产品。但是我在当时其实就看到有不少非技术用户尝试使用 Claude Code，比如当时的 B 站就能搜到一些关于 Claude Code 配合 Obsidian 使用的视频，而 CLI 的这么一个形态对于非技术用户来说肯定是不太友好的。同时这类的 CLI Agent 基本上都存在难以配置第三方大模型服务的问题（基本都需要手动改配置文件，很不直观），于是我就想做一个 GUI 的桌面 Agent 应用。

不过可惜，看到有这个需求是一回事，实际执行又是另一回事。我当时对于 Agent 的了解并不足够，技术栈的选择和使用 AI 编程的经验也有限，这就导致我当时做的原型版本从功能定位到技术栈选择都明显跑偏。

在约半年后（差不多是在 2025 年十一月）我重新拾起这个项目，重新开始开发。其实现在想来我在后来才重新正式开始开发这个项目也有几点好处：

  1. 这时我对 agent 的了解更深入，也对主流的 agent coding 工具有了一定的体验
  2. 相关的库更为成熟，比如 Vercel 的 AI Elements 组件库
  3. 在一些交互上有了先例可以参考

这个项目我还是非常投入的。我自己开发了一个基于 openai 和 anthropic sdk 的 ai sdk Dais-SDK，在其中也封装了工具 schema 生成、skill 解析等 agent 开发中的常见需求，我对于它的定位其实更像是一个“Agent 的 Meta-framework”，一个“元框架”，即可以用来构造 agent 框架的框架。

除了 Dais-SDK 外，我还开发了：

  • Dais-Shell - 一个 LLM 友好的 shell 运行时
  • Dais-ScanTree - 一个 LLM 友好的目录扫描工具库

VPS

这半年里，我第一次尝试购买了 VPS 使用，虽然一定程度上是被迫购买的。

大概是这样的，很长一段时间里，我都是在白嫖一些云服务商提供的免费 docker 容器使用，比如 zeabur 和 render 之前都有提供免费的 docker 容器。但是这半年里，zeabur 取消了免费层级的 docker 容器，render 也收紧了免费容器的出入站流量限制，这就导致对于我的需求已经没法找到新的合适的白嫖资源使用了。另一方面，我需要多个容器，而云服务商的免费容器往往限制一个账号只能有一个，我也就不得不注册多个账号切来切去，还要用 cronjob 什么的来做容器的保活，其实虽然是白嫖的，但维护所要付出的时间成本并不低，可以说就是在花时间省钱。

后来尝试在 zeabur 买了一个 2C2G 的云服务器，体验确实还行，原本是首月一刀后续两刀，后来又涨价到三刀。虽然说 2G 由于 zeabur 官方的运维工具实际可用的内存少了两三百兆，不过容器管理挺方便，并且这个价格相比于我之前付出的管理精力也算值得了。

学业

这上半年也是我待在大学中的最后半年了。我花了不少时间完成毕业设计，在过程中 Dais 也是帮了不少忙，比如我通过 playwright-mcp 来让它帮我爬文献什么的。

我的毕设项目使用了我之前开发完成的 InputShare2，因此省去了不少项目开发的时间，前后花了一个多月的时间把毕设的论文完成。

也是得益于 Dais 在毕设中的实际应用，我也做了不少改进。比如在我的论文工作区中，我一直有让 Dais 帮我维护一个文献总结目录，即对于列入参考文献的每篇文献都写一份总结放到该目录中，它要读文献时优先读该目录下的总结。我后来就发现，这个目录就非常适合作为 Dais 的 Notes，于是参考了 Claude Code 的文件系统 Based 记忆功能的设计后给 Dais 设计了一套 Workspace Notes 机制。

最后一个学期的课程安排也还算合理，共两门课程，其中一门需要考试，另一门纯看课程作业。最后也是顺利通过了毕业设计和考试，成功毕业。

就业

这几个月也陆续投了一些简历，其中有过两次杭州中大厂的面试，一个是 agent 开发岗，要求较高没有通过；另一个是前端转全栈岗，本来是面试通过，已经通知了入职事项，在等了几天 offer 后突然通知由于内部调整没法发这个 offer，只得作罢。后来又通过 L 站获得了几个初创公司的面试机会，反馈也都挺好，最后去了其中一家。
