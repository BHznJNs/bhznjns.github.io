电脑使用手机摄像头类应用调研

Iriun Webcam

  • 打开 PC 端和手机端自动连接
  • 支持局域网和 USB 连接
  • 只支持横屏

iVCam

  • 支持竖屏拍摄
  • ⚠️ 有广告

DroidCam

Classic Version

  • 仅支持横屏拍摄

DroidCam Webcam

  • 官方提供 OBS 插件支持
  • 我在使用时无线连接无法正常连上，仅有线连接能正常用
  • 依然仅支持横屏拍摄

Camo

  • 电脑端和安卓端的 UI 风格偏向原生（Fluent UI / Material You），界面美观
  • 支持横屏和竖屏拍摄
  • 在手机开热点与电脑连接的情况下无法使用无线连接
  • 支持有线连接
  • 启动后会设置虚拟摄像机，可以直接在 OBS 中添加

综合下来，Camo 是最佳方案。
