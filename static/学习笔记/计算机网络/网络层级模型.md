# 网络层级模型

## TCP/IP 五层模型

1. {Application}(应用层): HTTP, FTP, SMTP
2. {Transport}(传输层): TCP, UDP
3. {Network}(网络层): IP
4. {Link}(链路层): 以太网，ATMP, WIFI
5. {Physical}(物理层): 光纤、无线电等物理线路

## ISO/OSI 七层模型

在五层模型的应用层中多了额外两层：
1. {Presentation}(表示层): 加密、压缩
2. {Session}(会话层): SSL, TLS

## 每一层的作用

- Physical Layer: This layer is responsible for the physical transmission of bits "on the wire"
- Link Layer: handles data transfer between neighboring network elements
- Network Layer: the routing of datagrams from source to destination
- Transport Layer: provides process-process data transfer
- Session Layer: synchronization, checkpointing, and recovery of data exchange
- Presentation Layer: allows applications to interpret the meaning of data
- Application Layer: supporting network applications
