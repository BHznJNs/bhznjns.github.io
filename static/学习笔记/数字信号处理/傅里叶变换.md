# 傅里叶变换

将信号从时域转换到频域

Discrete Fourier series:
$$$
a_k = \frac{1}{N} \sum_{n=0}^{N-1} x[n] \exp\left( -j \frac{2\pi}{N} kn \right)
$$$

Inverse of the discrete Fourier Series:
$$$
x[n] = \sum_{k=0}^{N-1} a_k \exp\left( j \frac{2\pi}{N} kn \right)
$$$

其中

$$$
\exp\left(-j \frac{2\pi kn}{N}\right) = \cos\left(\frac{2\pi kn}{N}\right) - j\sin\left(\frac{2\pi kn}{N}\right)
$$$

>>>计算例 1
Periodic signal: $$x[n] = [0 \quad 2 \quad 4 \quad 6]$$, period N=4

$$$
a_k = \frac{1}{4} \sum_{n=0}^{3} 2n \exp \left( -j \frac{2\pi kn}{4} \right) \quad \text{for } 0 \le k \le 3
$$$
