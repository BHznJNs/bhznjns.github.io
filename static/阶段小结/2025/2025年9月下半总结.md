# 2025 年 9 月下半总结

这半个月的时间主要花在了 InputShare 付费版本的开发上。

## 独立开发

半个月时间，把 InputShare 新版本的基本流程给跑通了：
1. 换了全新的技术栈：Tauri（为了用 web 技术栈加速开发）+ Python（为了复用原先的一些代码和逻辑）
2. 后端 API + 前端调用
3. 多设备管理
对于安卓端，也决定用 Jetpack Compose 重构（这里吐槽一下，之前的版本在编写的时候由于我完全没有安卓开发经验，代码几乎都由 AI 编写。结果 AI 完全使用 XML 来编写页面），同时将相关的 API 都换成更现代的写法。

### Vibe Coding

在开发 InputShare 新版本时，也是延续了上个项目的经验，前端部分主要由 AI 编写。同时由于这个项目使用了 shadcn-ui（不同于之前项目直接使用 radix-ui），界面风格更统一，代码也更具可维护性。同时在开发中我也尝试使用了 Roo Code 的 sub-task 功能，利用子 task 下上下文隔离的特性，让 AI 在有限的上下文下能够辅助读遍项目中的所有代码文件帮忙重构。

## 求职就业

之前面试字节的三面后过了一周多，本以为没有通过，结果在第二周收到消息，说是通过了三面，安排参加 HR 面。
在 HR 面中，对方提到了有关提前实习的接受度，面试完后就感觉不对劲。果然后续的沟通中说明，不给校招 offer，只有实习 offer，且转正率未知。由于我相对于一些同龄的卷王还是比较缺乏实习经验的，再加上字节实习薪资较高，食宿都有补贴，这个 offer 其实还是比较有吸引力的。当时通知正好是周五，我犹豫了一个周末后决定拒绝。也算是破釜沉舟，让自己全心去把 InputShare 这个项目完成了。

当然，我也不是没有考虑到项目失败的风险，主要是念在 InputShare 这个项目同时也作为我的毕设项目，至少我可以在这个学期内将毕设完成，有需要的话下个学期还是有时间找实习的。

## 游戏娱乐

这个半月中把以前很喜欢的皇室战争重新拾起游玩，游戏本身确实很有意思，哪怕这已经是差不多十年前发布的游戏。但是游戏的运营属实是有些难评。
