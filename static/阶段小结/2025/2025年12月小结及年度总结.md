# 2025 年 12 月小结及年度总结

由于实在过于拖延，2025 年已经结束了将近一个月了才开始写总结，干脆就把 2025 年 12 月的小结和 2025 年年终总结一起写了。

## 2025 年 12 月小结

### InputShare2

这个月又将 InputShare2 最后的一点问题给优化了下，开始着手于软件的推广了。
在 B 站、小红书、抖音、LinuxDo 以及小众软件论坛上都发布了内容，总体来说还是 B 站的推广效果最好，其次是 LinuxDo 和小红书。也尝试过开闲鱼店铺售卖，但是一份也没卖出去。后来也尝试发布了一些 GEO 内容在什么值得买、CSDN 等平台上，不过效果不明显。

此外还给 InputShare2 加上了通过悬浮球快捷发送文件的功能，并且编写了自动化构建 MSIX 包的 GitHub CI。

### Dais

在与 Gemini 交流一番后决定将之前的 Daigent 项目改名为 Dais，用 Nano Banana 生成了软件图标，软件本体以及使用的 LiteAI-SDK 也迭代了好几个版本。

## 接下来才是我的年度总结

这一年是我正式开始尝试独立开发，尝试做付费软件变现的一年。

### 这一年里我的最大变化

这一年里我的最大变化就是开始写日志了。从最开始使用 logseq，到后来由于 logseq 过于卡顿而切换到功能更丰富的 Obsidian。关于开始写日志的原因和作用，我在[此文](/杂谈/我开始写日志了.md)中已经介绍过了，这里就不再赘述。

### 2025 年我的小目标

在 2025 年年初时，我就给自己定了一个小目标，通过 InputShare 项目变现，把我在 2024 年时买平板的钱赚回来。到了年底时，看了下微软商店上的数据，差不多卖了九十多刀，也算是赚回来了。

### 2025 年，我与 AI

2025 年也是我开始尝试使用 AI 来提高生产力的一年。从最开始的尝试 Copilot 自动补全和 Agent 模式，到后来使用 Cline + Gemini 免费 API Key，再到用 Roo Code 来替换 Cline，并自建 New API 来聚合多个渠道，以此在零成本的前提下实现了 API 自由。
我在使用 Roo Code 之后也尝试过后来大火的 Claude Code 和 Codex，可惜这俩在我手里的效果并不理想，还是用顺手的工具用着舒服。
我也尝试过开发一些 AI 相关的程序项目。比如我的独立开发的试手产品”狸语字幕助手“，这是我为了解决我在直播写代码时不想开麦的小痛点而做的基于 ASR 模型的桌面应用程序。又比如我之前为了利用起来自建 New API 中接入但又用不上的小参数模型，编写了一个自动化脚本来帮我过滤 LinuxDo 站点的帖子。我目前也在尝试开发一个 LLM Agent 桌面客户端程序，我希望能在 2026 年春节前拿出 MVP 版本。

2025 年也是 LLM 技术大跃进的一年。我印象特别深的是，2025 年年初时，Google 的最新 LLM 还是 Gemini 2.0 Pro，我当时不屑一顾；到了年中时 Gemini 2.5 Pro 的能力已经够我用来结伴编程；再到年尾时我已经完全依赖于 Gemini 3.0 Pro，无论什么事都要打开一问。得益于模型能力的进步，2025 年似乎也成为了 LLM Agent 元年，Vibe Coding 也成了 Agent 最早的应用场景。

### 技术上的成长

2025 年，我在技术上主要是广度上有了成长。
年初时我通过“NFC 纸质链接”的[NFC PLinkD](https://github.com/BHznJNs/NFC-PLinkD) 项目（回顾时吐槽一下，我到现在都觉得这个项目的概念是挺可以的，但是“NFC PLinkD”这个名字起得过于自嗨了，不过“电纸链接”这个中文名字还是很不错的），我开始通过 Flutter 来接触移动端开发；
到四五月时，我为了给 InputShare 项目构建更好的图形界面，尝试基于 PySide6 封装 WebView 库 [PyQWebWindow](https://github.com/BHznJNs/PyQWebWindow)，这也是我发布的第一个 PYPI 包。
再到暑假时我为了提高项目构建效率封装了几个可复用的 GitHub Action。
在暑假中我开发的”狸语字幕助手“中所使用的 Tauri + Python 的技术栈也成为我后续开发桌面应用程序中使用的技术栈。
在暑假尾声中，我借由试手开发的 [llm-hooks](https://github.com/LLM-Hooks/llm-hooks) 项目，也逐渐地有了些全栈开发的经验。
