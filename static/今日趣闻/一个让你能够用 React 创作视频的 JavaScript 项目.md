# 一个让你能够用 React 创作视频的 JavaScript 项目

项目地址：[remotion.dev](https://www.remotion.dev/)
在线编辑器 Demo：[https://remotion-helloworld.vercel.app/?/HelloWorld](https://remotion-helloworld.vercel.app/?/HelloWorld)

- - -

## 基本介绍

这个项目让你能够通过编排组合 React 组件来创建视频。也得益于此，创建的视频实际上是可以动态渲染的，项目也提供了专门的 ``<Player>`` 组件用于直接在网页中基于动态的 React 状态播放使用 remotion 创建的视频。具体可以[见此](https://www.remotion.dev/docs/player)。

项目有部分高级功能，如高级的动画效果等需付费，定价[见此](https://www.remotion.pro/license)。

## 付费的 NPM 包

有意思的是，这个项目为了通过一些付费功能变现（这些功能部分是以 NPM 包的形式交付的），基于 Stripe 设计了一个名为 [npm-kiosk](https://npm-kiosk.remotion.dev/) 的 NPM 销售模板。
