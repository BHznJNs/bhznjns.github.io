# 帮助老人解决电子产品相关问题的订阅服务
``2025/07/26``

该公司的官网网址：[Candoo Tech](https://www.candootech.com/)
相关介绍视频：[Candoo Tech aims to empower older adults with tech support](https://www.youtube.com/watch?v=YD8J4yapd2Y)

- - -

这是一家通过远程服务，帮助老年人更舒适地使用手机、电脑、平板电脑等电子设备。他们的服务内容包括一对一的技术支持和培训课程，涵盖了从设备设置到软件使用的方方面面。该公司还与养老社区、健康计划和医疗服务提供商等机构合作，为其客户提供服务。

他们的面向个人的收费策略分为两种：
1. 一次性服务，一次 $75.00，提供一对一的一小时在线会议指导
2. 订阅服务，一个人 $228/year，两个人 $340/year。包含一次最长九十分钟的在线会议指导，无限次数的{快捷帮助}(Quick Support)，以及对于电子设备疑难杂症的视频教程库的使用权。
