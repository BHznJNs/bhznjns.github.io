# 一种相比于常见数据存储格式更省 token 的数据格式

项目地址：https://github.com/johannschopplich/toon

比如对于 JSON：
```
{
  "users": [
    { "id": 1, "name": "Alice", "role": "admin" },
    { "id": 2, "name": "Bob", "role": "user" }
  ]
}
```

会被转换为：
```
users[2]{id,name,role}:
  1,Alice,admin
  2,Bob,user
```

相比于其它常见的数据格式，能够显著减少同样数据的 token 数量：
